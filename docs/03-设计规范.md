# 设计规范

## 视觉命题

像素风赛博外星酒吧：生物机械、高级、神秘、冷峻。主色为黑色、深青蓝与深灰；琥珀色只用于吧台暖光和少量焦点；蓝紫色用于全息信息与交互反馈。

视觉识别优先级为“酒馆 70–80%，外星/赛博元素 20–30%”。第一眼必须能辨认出吧台、酒架、杯具、调酒工作位和酒保；星球、舷窗、异形纹样与像素全息光只负责建立世界观，不能让场景看起来像观景厅、飞船驾驶舱或纯科幻展馆。

## 画布与层级

- 设计基准：1080 × 1920，比例固定为 9:16。
- 桌面端居中展示，外围使用低干扰暗色背景。
- 移动端优先占满可用视口，同时保留安全边距。
- 图层顺序：远景、酒吧背景、酒柜酒瓶、章鱼酒保、吧台、酒杯与 Flavor Profile、前景、Pour Focus 特效。
- 常态景深必须可读：酒柜与未拿起酒瓶属于后景，机械酒保属于中景，桌面酒杯及其接触阴影属于近景；拿起的酒瓶临时升到最前交互层。
- 视差最大位移依次为 ±2、±4、±6、±8、±10px；触控设备可降低或关闭视差。

## 首屏构图

- 顶部/后方：左侧为具有实体纵深的三层酒柜，19 个配料瓶全部直接可见并可拖拽；右侧为酒保工作位和次要的外星城市/舷窗背景。
- 三层酒柜按 7 / 6 / 6 混排瓶子并使用轻微错位，不追求机械整齐；禁止分页或把中国产品移到前台桌面。
- 酒柜交互容器必须完全透明，直接使用背景资产已有的三层木架；禁止在酒柜外围增加矩形或圆角边框、黑色半透明底板、内阴影或额外的 CSS 层板。不可见命中区可以保留，但不得形成可见外壳。
- 每排酒柜瓶身的瓶底必须落在背景木架承托线上；前台左侧五种中国产品允许采用前后两排形成桌面纵深，但两排瓶底都必须位于原图木质桌面范围内，不得落到吧台立面。
- AD 钙奶、旺仔牛奶、豆浆、桂花酒、青梅酒放在前台左侧原图木质桌面，采用两排轻微错位和不同纵深；它们属于近景桌面物件，但不得遮挡主酒杯、中文风味表或酒保面部。
- 酒柜和前台陈列态瓶子只显示瓶身资产，不在瓶底附加中文名或百分比；中文配料名仅在 Pour Focus 倒酒时显示。按钮仍通过无障碍名称提供配料名与当前比例。
- 中：吧台工作位后的机械章鱼酒保与放在实体桌面上的可交互酒杯，酒杯始终是操作焦点；常态使用所选杯型的杯具资产，倒酒特写切换到动态 SVG 酒杯。酒保下半身由扩大后的前台层遮挡，Flavor Profile 位于酒杯右侧并保持明确间距。
- 常态桌面直接取自当前背景图中的完整木质吧台，不新增覆盖它的 CSS 桌面。酒杯杯底落在木质台面中段，不得停在水平分隔线、吧台立面或控制区上。
- 下部：highball、tumbler、cocktail、collins 杯型选择与 `SERVE`，不再出现 Ingredient Array。
- 底部杯型选择只使用缩略图；不得在控制区再次渲染主酒杯或把桌面酒杯下沉到控制区。
- 顶部状态与底部操作均为贴边薄型 HUD；底部四个杯型和 Serve 同行，英文说明等次要文字可隐藏，但触控命中保持至少 44px。
- 游戏应直接进入可操作界面，不设置营销首页或无必要的开始页。

## MVP 资产策略

- 当前阶段不依赖正式美术资产，酒吧背景、机械章鱼酒保、八个酒瓶、酒杯和结果卡底板均必须有统一风格的 SVG/CSS placeholder。
- 可使用自行生成的 PNG/WebP 进行初步替换，但生成图只作为可独立开关的增强层，SVG/CSS placeholder 必须继续存在。
- 用户提供的 highball、tumbler、cocktail、collins 四张杯具图用于常态桌面酒杯；当前黑色背景通过暗场混合隐藏。进入 Pour Focus 时位图平滑淡出，动态 SVG 酒杯淡入并承载所有酒液变化；加载失败时直接保留 SVG 回退。
- 常态杯具不得成为第一主体：建议可见宽度约为画布 `15%–22%`，杯底位于场景高度约 `65%–72%` 的木质桌面区域，并增加低矮椭圆接触阴影。常态资产降低对比度和不透明度，避免烟黑玻璃像悬浮海报。
- 远景背景、酒吧结构、角色、吧台、瓶子、酒杯、前景、特效与结果卡底板分层管理，禁止把 UI、角色和道具合并成不可拆分整图。
- 背景资产需保留中央操作焦点和酒杯右侧信息面板的可读空间；角色资产不得包含玻璃、瓶子、按钮、文字或固定背景。
- 所有资产使用透明或可安全裁切的边界，约束在稳定容器内，通过 `object-fit`、定位变量和透明度适配，便于未来逐项替换。
- 统一风格：深青黑与石墨机械材质、少量琥珀焦点、稀疏蓝紫全息光；禁止水印、品牌标识和不可读装饰文字。

## 角色形象方向

- 机械章鱼酒保保留“多臂调酒”核心识别，但采用圆润、友好而精密的服务机器人比例：大圆头、简洁面屏或双眼、清晰机械关节、可执行调酒动作的多臂结构。
- 角色应明确位于吧台工作位内，姿态强调服务和调酒，而不是战斗、怪物展示或太空探索。
- 用户提供的机器人酒吧照片仅作为形体、工作姿态和酒馆空间关系参考，不复制其中品牌、文字、标识、具体外壳切线或商业产品造型。
- 像素化应服务于游戏统一风格，不降低角色轮廓、眼神、机械关节和手臂动作的可读性。

## 动效

- 章鱼待机：身体上下 2–4px，头部轻微旋转，触手缓慢摆动 3–5°，眼部呼吸发光。
- 抓瓶：缩放至 1.06、上移 6px、增强轮廓光。
- 接近酒杯：增强杯沿高光，章鱼前触手做轻微响应。
- 倒酒：瓶身自然倾斜并出现连续液流。
- Pour Focus：真正倒酒时常态杯具资产淡出、动态 SVG 酒杯淡入并平滑放大，环境降低亮度和清晰度、Flavor Profile 增强；杯旁以中文显示当前配料，松手后 250–450ms 内恢复为桌面杯具资产。
- 倒酒时液流必须连续连接瓶口与杯口，并清楚显示液面增长、入流冲击、扩散高光和波纹；即使倒入透明基酒，也不能因颜色过浅而看不到反馈。
- Pour Focus 中使用稳定的前景瓶倒酒姿态，液流必须从倾斜瓶口沿自然弧线进入杯口，不使用与瓶口脱节的垂直直线。
- Pour Zone 仅作为不可见的碰撞区域存在，常态、拖入和 Pour Focus 均不得显示蛋壳形、椭圆形或虚线外圈，也不得用整块区域底色包围酒杯。反馈只通过酒瓶、杯体、液流、中文配料名和 Flavor Profile 表达。
- 用户提供的吧台前景图只在 Pour Focus 中淡入并扩大裁切，用于建立酒杯特写的桌面质感和遮挡酒保下半身；常态场景由 CSS 吧台维持同样的遮挡关系。
- 酒液：液流命中时出现受控波纹、微小冲击凹面与颜色扩散；高粘度配料运动更慢，苏打增加气泡和少量泡沫。
- Serve：场景压暗、酒杯居中、卡片展开、信息依次出现，总时长 1.2–2.0 秒。
- 尊重 `prefers-reduced-motion`，减少持续漂浮和大幅过渡。

## 现实酒液约束

- 酒杯、液面、颜色混合、透明度、浑浊度和气泡遵循现实饮品观感。
- 不给液体增加霓虹描边、电路纹、发光颗粒或违反重力的运动。
- 赛博感来自环境、容器界面与灯光，不来自酒液本身。
- 气泡数量为 8–20，随 fizz 调整数量与上升速度。
- 粘度影响液面回弹与波纹速度；泡沫只在高 fizz 或高起泡配料时出现，不做永久白色顶层。
- 配方“分层”只在 Drink Card 作为比例信息图显示，不在真实杯中制造违反混合逻辑的固定色层。

## 可用性

- 常用文字不小于 14px，主要文本不小于 16px。
- 所有关键文字与背景保持清晰对比。
- 酒瓶提供可读名称，按钮有禁用状态，Flavor Profile 不只依赖颜色表达。
- 酒杯右侧 Flavor Profile 在 9:16 画布内完整可读；平时弱化但数值可读，Pour Focus 时增强，不移动到底部。
- Flavor Profile 标题与六维名称全部使用中文；情绪层置于六维风味下方，以中心为平衡点的双向轴呈现“忧郁—喜悦”，不用第七条单向百分比冒充情绪方向。
- 情绪描述分为“深沉、静思、平衡、明快、欢悦”五档，只描述配方气质；Pour Focus 中标记随配方平滑移动。
- 触控目标建议不小于 44 × 44 CSS px。
