## 5. 本地运行方式

前端命令必须在 `web/` 目录执行：

```powershell
cd "D:\新建文件夹 (9)\情绪酒馆\web"
npm.cmd run dev
```

预期地址：

```text
http://localhost:5173/
```

不要启动替代服务器来更新用户当前 GUI；如果 GUI 指向已有开发服务，应优先使用该服务并刷新页面。

Windows 下 Vinext/Vite 可能因 watcher 锁定 `.qa` 或浏览器 profile 报：

```text
EBUSY: resource busy or locked
```

如需浏览器 smoke：

- Chrome profile 放在 `%TEMP%`，不要放在 `web/.qa`。
- 不要同时启动多个 dev watcher。
- 使用 `CHOKIDAR_USEPOLLING=true` 作为环境变量启动的临时 workaround，但先确认没有旧 watcher 占用端口。

## 6. 建议验证顺序

先不要做视觉扩展，先确认基线：

```powershell
cd "D:\新建文件夹 (9)\情绪酒馆\web"
& .\node_modules\.bin\tsc.cmd --noEmit

npm.cmd run build
```

然后确认服务：

```powershell
Invoke-WebRequest -UseBasicParsing http://localhost:5173/
```

再执行已存在的浏览器 smoke：

```powershell
npm.cmd run test:browser
```

如果需要完整 lint：

```powershell

```

当前已知 lint 允许的既有 warning：`BarScene.tsx` 使用 `<img>` 的 Next 优化提示；不是阻断错误。
