# macOS 与 Xcode 说明

## 当前项目定位

本项目是网页游戏。开发和运行只需要 Node.js、包管理器与现代浏览器；Xcode 不是网页 MVP 的必需依赖。

## 在 Mac 上开发

- 推荐使用 VS Code、Cursor 或其他代码编辑器；也可以使用 Xcode 编辑文本，但其 Web/TypeScript 体验通常不如专用编辑器。
- 安装 Node.js 的当前长期支持版本，并使用项目锁文件对应的包管理器。
- 首次安装依赖前，先确认项目目录与本机缓存中是否已有可复用依赖。
- 保持文件名大小写一致；macOS 与部署环境可能比 Windows 更严格。
- 使用 Safari 和 Chrome 分别检查 Pointer Events、触控模拟、音画性能和 9:16 布局。

## 何时需要 Xcode

只有在后续明确增加以下目标时，才进入 Xcode 阶段：

- 使用 Capacitor 等方案封装为 iPhone/iPad 应用。
- 使用 WKWebView 制作原生容器。
- 进行 iOS 真机签名、调试、归档或 App Store 发布。

这些能力不属于当前 MVP。若未来启动 iOS 封装，应单独编写 iOS 架构、签名、权限、安全区、横竖屏、音频策略和发布流程，不与网页核心玩法耦合。

## 跨平台约束

- 不使用仅在 Windows 路径下才能运行的业务代码。
- 源码中的公共资源路径统一使用 Web 路径 `/assets/...`。
- 不依赖鼠标悬停完成核心操作，保证 iPhone/iPad 触控可用。
- 使用动态视口单位时提供合理回退，注意 Safari 地址栏和安全区域。
- 后续若加入音频，必须通过用户手势解锁播放，以兼容 Safari 策略。
