# 配料参数表

## 参数口径

- 本表是游戏内调酒参数，不代表真实商品的营养、配方或法定酒精标识。
- `ABV` 与 Sweet / Sour / Bitter / Fresh / Body、Opacity、Fizz、Cloudiness、Viscosity、Foam 均使用 `0–1` 归一化值。
- Sour 对应代码字段 `acidity`；其余字段分别对应 `sweetness`、`bitterness`、`freshness`、`body`、`opacity`、`fizz`、`cloudiness`、`viscosity`、`foam`。
- 颜色为动态酒液混色使用的 RGB；资产图片只负责瓶身外观，不作为运行时颜色采样源。
- `Mood` 对应代码字段 `moodValence`，范围为 `-1..1`：负值偏忧郁/深沉，0 为平衡，正值偏喜悦/明快。它描述调酒师对香气、味觉、口感和饮用氛围的叙事判断，不代表真实心理或酒精作用。

## 调参原则

- 金巴利、汤力水以 Bitter 为主轴；甜味美思、糖浆和乳饮料以 Sweet 为主轴。
- 汤力水、姜汁啤酒提供气泡和泡沫；乳饮料、豆浆提供高浑浊度与高酒体。
- 桂花酒、青梅酒保留可感知酒精度，但不超过基酒的 Alcohol 权重。
- 后续只在 `web/lib/ingredients.ts` 修改运行参数，并同步本表；不得在组件中写第二份数值。
