# 开发需求

## 产品目标

制作一个以 1080 × 1920 为设计基准的 9:16 竖屏网页互动游戏。玩家在赛博外星酒吧中拖动配料瓶向酒杯倒酒，实时观察液体和风味变化，最后生成专属 Drink Card。

## MVP 范围

- 赛博外星酒吧场景与轻量 2.5D 视差。
- 中央机械章鱼酒保及待机、倒酒响应动画。
- Gin、Rum、Vodka、Lemon、Lime、Honey、Oolong Tea、Soda 八种配料。
- 指针拖拽酒瓶；进入 Pour Zone 后每 100ms 增加 1%。
- 离开 Pour Zone、`pointerup` 或 `pointercancel` 时立即停止倒酒。
- 总比例不超过 100%，所有比例为整数。
- 动态酒杯、液面、颜色、透明度、浑浊度、气泡。
- 实时显示 Sweet、Sour、Bitter、Alcohol、Fresh、Body。
- 仅在杯中已有配料时启用 `SERVE`。
- Serve 后冻结配方并通过 1.2–2.0 秒动画生成 Drink Card。

## 本期不做

- AI 配方、数据库和账号系统。
- 经典鸡尾酒匹配、自动命名、情绪文案。
- Three.js、真实流体模拟和正式美术资产。
- 多页面、排行榜、分享、付费或联网玩法。

## 主要用户流程

1. 进入游戏后直接看到酒吧场景、中央酒杯、酒杯右侧 Flavor Profile，以及下方八种配料瓶。
2. 抓起配料瓶并拖到酒杯区域。
3. 停留期间持续倒酒，酒杯和风味数据同步变化。
4. 松手后倒酒立即停止，瓶子回到原位。
5. 配方非空时点击 `SERVE`。
6. 场景压暗、酒杯居中，生成包含配方与风味的 Drink Card。

## 首屏信息布局

- 下方配料区以八种酒瓶为唯一主要内容，不再放置 Flavor Profile。
- Flavor Profile 固定在酒杯右侧，始终与当前配方同步，且不能遮挡 Pour Zone。
- `SERVE` 保留为独立的流程动作，使用紧凑操作条与配料瓶区分层，不能挤占酒瓶识别空间。

## 完成定义

桌面与移动浏览器中都可完整完成上述流程；触控和鼠标操作一致；无计时器残留、比例越界或明显布局裁切；临时视觉资产可独立替换。
